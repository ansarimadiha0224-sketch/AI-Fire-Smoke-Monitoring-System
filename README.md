# 🔥 AI Fire & Smoke Monitoring System

A real-time computer vision application for detecting fire and smoke using **YOLOv8**, **OpenCV**, and **Python**.

---

## 🚀 Features

- 🔥 Real-time Fire Detection
- 💨 Smoke Detection
- 📷 Live Webcam Monitoring
- ⚡ YOLOv8 Object Detection
- 🖥️ Real-time Visualization
- 🚀 CPU & GPU Support

---

## 🛠 Tech Stack

- Python
- OpenCV
- YOLOv8
- PyTorch
- NumPy
